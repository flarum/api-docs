IconImageApi  

class IconImageApi

The API surface of an icon image, for a resource whose model uses HasIconImage. Add the endpoints and fields to the resource:

public function endpoints(): array { return [...IconImageApi::endpoints(), ...]; } `POST /{type}/{id}/icon-image` takes the file as the `iconImage` form field, `DELETE /{type}/{id}/icon-image` clears it. Both return the resource. They save the model directly, not through the resource's saving hooks, and dispatch Event\IconImageSaving before the change and Event\IconImageChanged after it instead. The model's iconImageUploader() stores the image. The endpoints are named `iconImage.upload` and `iconImage.delete`, so an extension can alter them with the ApiResource extender.

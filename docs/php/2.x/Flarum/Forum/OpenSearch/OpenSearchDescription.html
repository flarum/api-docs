protected array images()

The favicon, embedded rather than linked: Firefox refuses linked icons over 10KB, and an embedded one doesn't depend on where assets are served.

Images that would make the document too big for Chrome are left out, and Chrome then shows the forum's /favicon.ico. Kept for a day by where the favicon is stored, which changes when it is replaced, so it isn't read and resized on every request.

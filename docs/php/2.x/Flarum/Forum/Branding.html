Flarum\Forum\Branding\Listener

Classes

AppIcon
The uploaded app icon. Its source is kept, so the home screen icons can be drawn again when the background colour changes.
Branding
Where the forum's logos and icons are. An image a theme sets with the Theme extender takes the place of one an admin uploaded.
IconSet
Draws the favicon and app icon files from the data of one source image.
ShortName
The forum's name where its full title doesn't fit: a browser's list of search engines, or under an icon on a phone's home screen.
StoredFiles
The files derived from an uploaded image, each named in a setting.
ThemeImages
The logos and icons a theme sets with the Theme extender.
WebManifest
The forum's web app manifest, which Android and Chrome read for the name and icons of a shortcut added to the home screen. It opens the forum in the browser: running as an installed app is left to extensions that add what an app needs, such as offline support.

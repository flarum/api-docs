ThemeImages  

class ThemeImages

The logos and icons a theme sets with the Theme extender.

Each is drawn into the assets directory the way an upload would be, and drawn again only when its file's contents or its options change. A file is only read again when its size or modification time changes. What was drawn is kept in a setting, so clearing the cache doesn't draw it again. While a theme sets an image, the setting an upload of it is kept in holds the drawn file instead, when that is the kind of file an upload would be. The upload is put back when the theme stops setting the image. Files an image no longer uses are kept for 30 days, for pages and emails that still show them, and taken back if the image returns to them.

Constants

STATE_KEY

VERSION

Raise to draw every theme image again, after changing how they are drawn.
KEEP_RETIRED_FOR

How long, in seconds, the files an image no longer uses are kept.

image => [setting => the drawn file it holds].

ShowOpenSearchSuggestionsController  

class ShowOpenSearchSuggestionsController implements RequestHandlerInterface

Discussions a browser suggests as someone types in its search box, in the OpenSearch suggestions format: the query, then titles, descriptions and addresses. Only discussions the visitor can see are suggested.

Titles are matched on the start of their words, so a word is completed as it is typed. The forum's search matches whole words on MySQL, MariaDB and PostgreSQL, so it can't suggest anything until a word is finished. A word starts after anything that isn't a letter or digit, as in "[Solved]" or "carbon-fibre", which LIKE can't express. The database finds words at the start of a title or after a space; when they are too few, it finds titles that contain the words, and where the words start is checked here.

MAX_WORDS

Words of the query that are matched; the rest are ignored, so a long query can't build an unbounded number of conditions.
CANDIDATES

Recently active titles containing the words that are checked for words starting after punctuation, when too few start after a space. Older matches after punctuation are missed when this many titles only contain the words inside other words.

protected void pauseQueue()

Pause every queue on the active connection for the duration of the migration.

This mirrors what `queue:pause --all` does — including its refusal to act when pausing is disabled, since a flag no worker will read is only misleading state — but without a console Application to `call()` into, which Flarum's command base does not provide.

protected bool hasPendingMigrations()

Is there any migration — core or extension — that has not run yet?

A read-only comparison of the migration files on disk against the ledger of what has run, with no side effects, so it is safe to ask before deciding whether the run is worth pausing the queue for.

    when

    • when(
          condition: boolean | ((app: Application) => boolean),
          extenders: () => IExtender<any>[],
      ): this

      Apply extenders based on a condition.

      Conditions are checked before the application boots, so app.forum and app.session aren't available yet. Use whenForumAttribute() to check a forum attribute.

      Parameters

      • condition: boolean | ((app: Application) => boolean)

        A boolean, or a callback returning a boolean.

      • extenders: () => IExtender<any>[]

        A callback returning an array of extenders.

      Returns this

      Example

      new Extend.Conditional()
        .when(
          () => 'flarum-tags' in flarum.extensions || 'flarum-mentions' in flarum.extensions,
          () => [new Extend.Model(Discussion).attribute<boolean>('acmeIsLinked')]
        )

    whenForumAttribute

    • whenForumAttribute(
          key: string,
          expected: unknown,
          extenders: () => IExtender<any>[],
      ): this

      Apply extenders only if a forum attribute matches an expected value.

      Uses strict comparison (===). The value is read from the forum payload, as app.forum doesn't exist yet when extenders are applied.

      Parameters

      • key: string

        The name of the forum attribute.

      • expected: unknown

        The expected value.

      • extenders: () => IExtender<any>[]

        A callback returning an array of extenders.

      Returns this

      Example

      new Extend.Conditional()
        .whenForumAttribute('acmeAdvancedMode', true, () => [
          new Extend.Routes().add('acme.advanced', '/acme/advanced', AdvancedPage),
        ])

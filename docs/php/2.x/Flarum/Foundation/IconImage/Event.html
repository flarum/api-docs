Flarum\Foundation\IconImage\Event  

Classes

IconImageChanged
Dispatched once a model's new icon image, or its removal, has been saved through the icon image endpoints. `$model->icon_image_path` is null when the image was removed. The change is already stored when it is dispatched: a listener that throws fails the request but doesn't undo it.
IconImageSaving
Dispatched before a model's icon image is stored or removed through the icon image endpoints, which don't run the resource's own saving hooks. A listener can throw to stop the change, or alter the image before it is stored. Check `$model` to act on one kind of model only.

HandlesWebhooks  

interface HandlesWebhooks

An optional capability for {DriverInterface} implementations whose provider can push delivery events (bounces, complaints) to Flarum via an inbound webhook.

This is intentionally a separate interface, not part of DriverInterface, so that adding bounce handling never breaks third-party drivers that do not implement it.

RequestParserInterface getWebhookRequestParser( SettingsRepositoryInterface $settings)

The Symfony request parser for this provider. The parser is fully responsible for **authenticating** the request and normalising the payload into a {\Symfony\Component\RemoteEvent\RemoteEvent}.

Verification is provider-specific and lives entirely in the parser — it may check an HMAC signature (Mailgun), an account-specific IP allowlist, or an SNS certificate (SES). Callers MUST NOT attempt to verify the request themselves; they should call {\Symfony\Component\Webhook\Client\RequestParserInterface::parse()} and treat a thrown {\Symfony\Component\Webhook\Exception\RejectWebhookException} as a rejection, and a `null` return as "verified but no actionable event" (e.g. an SES/SNS subscription-confirmation handshake).

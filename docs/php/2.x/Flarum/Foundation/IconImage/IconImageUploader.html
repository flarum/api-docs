IconImageUploader  

class IconImageUploader

Stores an image used in place of a model's Font Awesome icon (a group's or a tag's, for example). The model needs the `icon_image_path` and `icon_image_scales` columns; see the HasIconImage concern.

Each upload is stored as a static WebP, its transparent border trimmed, and scaled to fit a square box at 1x, 2x and 3x without cropping, so that an image can be shown whole next to a label or cropped to a badge's shape by the browser. A model can use a subclass, with another box size, scales or disk, by overriding HasIconImage::iconImageUploader().

protected void trimTransparentBorder( ImageInterface $image)

Crop away a fully transparent border, so that the artwork, not the empty space around it, fills the glyph-sized box it is shown in. Only transparency is trimmed: a solid background is part of the design.

The border is found on a small copy, which is quick whatever the source's size, and the crop errs on the side of keeping pixels.

    Class TypingActivitySource

    Who is typing where, forum-wide, from flarum/realtime's typing-activity channel. The server only sends each subscriber what they could see anyway (discussions they can see, names of members hiding their online status only with user.viewLastSeenAt), so this renders what arrives as it is.

SessionConfig  

class SessionConfig

How long sessions and the tokens behind them last.

Every value here is answered the same way: `config.php` first, then the settings table, then the default that has always applied. Putting a value in `config.php` is therefore also a way to take it away from the admin panel — a site owner can pin session lengths where an administrator cannot loosen them, which is the point of keeping the option in a file rather than only in the database.
